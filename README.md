## 二、程式目的

本作業透過 Python 基本資料型別與字串處理方法，
整理「桌遊體驗」及「電影欣賞」兩場活動的報名資料。

將原始文字名單中的空白及大小寫統一處理後，
利用集合去除重複報名，並透過交集、聯集及差集
比較兩場活動的參加者，最後計算各場活動人數、
總不重複人數、報名人次及應收費用。

## 三、程式功能

- 移除姓名中的半形空白並統一轉為小寫。
- 將原始文字轉換為保留順序及重複項目的串列。
- 使用 set 去除同一場活動的重複報名。
- 使用交集取得兩場活動的共同參加者。
- 使用聯集取得全部不重複參加者。
- 使用差集取得只參加單一活動的名單。
- 依照英文字母順序排列參加者名單。
- 使用切片取得前兩位通知名單。
- 計算各場活動人數、報名人次及應收費用。
- 使用 f-string 輸出完整摘要。

## 四、使用的 Python 資料型別

| 資料型別 | 變數名稱 | 用途 |
| --- | --- | --- |
| str | board_raw、movie_raw | 保存原始文字名單 |
| tuple | activity_names | 保存固定的活動名稱 |
| list | board_list、movie_list | 保存整理後的姓名及重複項目 |
| set | board_set、movie_set | 去除重複報名及進行集合運算 |
| dict | unit_fees | 保存各場活動的單人費用 |
| dict | summary | 保存人數、人次及應收費用 |

## 九、個人問題回答

### 問題一

測試一中，整理後的桌遊串列有 4 筆資料，
為什麼桌遊費用應以 3 人計算？
直接把字串拆成 list，和再轉成 set，
各自保留了什麼、失去了什麼？

回答：

因為原始名單中的 Amy 重複報名，
統一大小寫後，實際上只有 amy、ben、cora
三位不同的參加者，因此費用應以 3 人計算。

使用 list 可以保留姓名的排列順序及重複項目，
但無法自動排除重複報名。轉換成 set 後，
可以去除相同的姓名並保留不重複的參加者，
但不再保留原始排列順序及重複次數。

因此，桌遊應收費用為 3 × 120 = 360 元。

### 問題二

測試三中，兩場活動只有 3 位不同的人，
為什麼是 6 人次、總應收仍是 600 元？

回答：

測試三的兩場活動經過集合去重後，
參加者完全相同，因此兩個集合的交集與聯集
皆為 amy、ben、cora，總不重複人數為 3 人，
而兩個方向的差集皆為空集合。

由於每位參加者皆參加兩場活動，
所以報名人次為 3 + 3 = 6 人次。

兩場活動的費用需要分別計算，
因此總應收為：

3 × 120 + 3 × 80 = 600 元。
